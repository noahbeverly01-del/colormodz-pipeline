Privacy Policy

ColorModz Pipeline · Effective October 14, 2026

ColorModz Pipeline (“the tool”) is a personal, self-hosted tool used only by the owner of the ColorModz YouTube channel. It has no other users and does not collect information from the public.

YouTube API Services

The tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data the tool accesses

  • YouTube Data API: uploads videos, thumbnails and caption tracks to the channel owner's own channel, and reads back the resulting video IDs and upload status.
  • YouTube Analytics API: reads aggregate performance figures for the owner's own videos, such as views, click-through rate, average view duration and audience retention.
  • Google sign-in: an OAuth access token and refresh token that let the tool act on the owner's channel.

The tool does not access any other channel's private data, viewers' personal information, comments, subscriber lists, or any Google account data beyond the permissions listed above.

How the data is used

Data is used only to publish the owner's videos and to track how they perform, so future videos can be improved. It is not used for advertising, profiling, or any other purpose.

Storage and security

The OAuth token and analytics figures are stored on servers the channel owner personally owns and operates. Analytics figures are kept for as long as they are useful for planning videos; the owner can delete them at any time. Tokens are kept in a private, read-only location that is not exposed to the internet.

Sharing

Data obtained through YouTube API Services is not sold, rented or shared with third parties. If the owner enables an optional hosted AI writing service, a short summary of the channel's own analytics figures may be sent to that service to draft notes; no Google credentials are ever sent.

Revoking access

Access can be revoked at any time from the Google security settings page (Third-party apps & services). Revoking access stops the tool from uploading or reading analytics immediately.

Changes and contact

If this policy changes, the updated version will be posted on this page with a new effective date. Questions can be raised by opening an issue at github.com/noahbeverly01-del/colormodz-pipeline.
